# ChatApp UI

A modern real-time chat application frontend built using **React** and **Vite**.  
The project provides a fast, responsive, and interactive user interface for seamless communication.

---

## Features

- Real-time chat interface
- Responsive UI design
- Fast development with Vite
- Component-based React architecture
- ESLint integration for code quality
- Hot Module Replacement (HMR)

---

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- ESLint
